## 🚀 Projetos

### 🎯 [Job Tracker Pro](https://github.com/josezaltar/Job_tracker) · [demo](https://job-tracker-seven-ecru-36.vercel.app)
Aplicação full stack para organizar candidaturas a vagas, com conta demo para visitantes.
- API REST em Node.js, Express e TypeScript com PostgreSQL e autenticação JWT
- Front-end em React 19, Redux Toolkit, RTK Query e Tailwind CSS
- **Extensão para Edge/Chrome com IA:** analisa a vaga aberta, dá uma nota de compatibilidade com o currículo, mostra o que falta e salva no tracker
- Deploy: Vercel + Render + Neon · testes automatizados na extensão

### 📱 [Twiclone](https://github.com/josezaltar/Twiclone)
Rede social inspirada no X (Twitter).
- API em Django REST Framework com JWT, comentários aninhados em até 3 níveis, curtidas, retweets e seguidores
- Front-end em React 19 e TypeScript, com upload de avatar e banner e tema claro/escuro

**Stack:** React, TypeScript, Django REST Framework, SQLite, Zustand, Styled Components

### 🧾 [API de Pedidos](https://github.com/josezaltar/Desafio_Jitterbit)
Desafio técnico: API REST de pedidos com Node.js, Express, PostgreSQL, JWT e documentação em Swagger.
