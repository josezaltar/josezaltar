## 🚀 Principais Projetos

### 📱 [Twiclone](https://github.com/josezaltar/twiclone)
**Rede Social Completa inspirada no Twitter/X**

Rede social completa desenvolvida com React 19, TypeScript, Python e Django REST Framework. O projeto implementa:
- ✅ Autenticação JWT
- ✅ CRUD completo de tweets com comentários aninhados (até 3 níveis)
- ✅ Sistema de curtidas e retweets
- ✅ Relacionamentos entre usuários (seguir/deixar de seguir)
- ✅ Upload de avatar e banner
- ✅ Tema claro/escuro
- ✅ Feed personalizado
- ✅ Deploy em produção (Netlify + PythonAnywhere)

**Stack:** React 19, TypeScript, Django REST Framework, PostgreSQL, Zustand, Styled Components

### ⚖️ [Calculadora de IMC](https://github.com/josezaltar/calculadora-imc)
**Aplicação Interativa de Saúde**

Aplicação interativa desenvolvida com React 19 e Vite, focada no cálculo do Índice de Massa Corporal (IMC). Totalmente componentizado, com hooks (useState), validações de entrada e feedbacks personalizados.

**Stack:** React 19, Vite, CSS Modules, JavaScript
